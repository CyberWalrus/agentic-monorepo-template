Реализуй в этом репозитории фичу «приоритет задачи». Работай автономно: сначала прочитай AGENTS.md в корне и следуй его правилам и скилам.

Фича:

- Контракт (`packages/contracts`): у задачи поле `priority` со значениями `low` | `medium` | `high`, по умолчанию `medium`; вход создания задачи принимает опциональный `priority`; `openapi.json` перегенерировать.
- API (`apps/api`): приоритет сохраняется и возвращается вместе с задачей.
- UI (`apps/web`): в форме создания задачи — выбор приоритета; в списке приоритет отображается меткой рядом с задачей.
- E2E (`e2e/features/tasks/`): сценарий — создание задачи с приоритетом и проверка отображения метки приоритета в списке.

Критерий готовности: `pnpm verify --full` зелёный. Скриншот-тесты не запускай и их базлайны не обновляй. Защищённые пути (`tools/protected-paths.json`) не меняй, тесты и гейты не ослабляй, `.skip`/`.fixme`/`.only` не добавляй. Если что-то блокирует — остановись и опиши блокер в финальном ответе.
