# Route states

E2E-план фичи route-states: AC2 задачи C5 («Состояния интерфейса и
доступность как гейты», план из PR #24). Ошибочные и несуществующие
маршруты показывают компоненты состояний из `@repo/ui` (дефолты роутера),
а не пустой экран; гейт дерева маршрутов — `apps/web/src/router-gate.test.ts`.

## Критерии приёмки

- **AC-2**: Неизвестный URL показывает понятную страницу not-found («Page not found») со ссылкой «Back to tasks», ведущей обратно в список задач.

## Сценарии

- `shows a not-found page for an unknown URL and navigates home` — открыть несуществующий URL, увидеть not-found, перейти по «Back to tasks» и оказаться в списке задач (SSR-рендер).
