# E2e reporting

E2E-план контура диагностики падений (C4): логи API прикладываются к отчёту
Playwright при падении теста. Критерии приёмки; у каждого есть хотя бы один
тест в `e2e/features/e2e-reporting/` — это проверяет гейт трассировки
(`e2e/features/traceability/traceability.spec.ts`).

## Критерии приёмки

- **AC-1**: При падении E2E-сценария вложение `api-logs` в отчёте содержит логи API именно этого сценария (отбор по идентификаторам запроса из C4.1) и не содержит записей соседних параллельных тестов.
- **AC-2**: Канарейка: намеренно падающий сценарий (e2e/agents/api-logs-canary.spec.ts) даёт отчёт с непустым вложением логов.
- **AC-3**: Красный прогон называет путь к вложению в stdout — ровно тот вывод, который `pnpm verify --json` кладёт в поле `output` красного шага `e2e`.
