# Tasks

E2E-план фичи tasks. Критерии приёмки; у каждого есть хотя бы один тест в
`e2e/features/tasks/` — это проверяет гейт трассировки
(`e2e/features/traceability/traceability.spec.ts`). Сценарии идут параллельно:
данные через `uniqueTitle()`, порядок не assumes.

## Критерии приёмки

- **AC-1**: Пользователь создаёт задачу с непустым заголовком — задача появляется в списке, поле ввода очищается.
- **AC-2**: Пользователь отмечает задачу выполненной — состояние галочки сохраняется после перезагрузки страницы.
- **AC-3**: Попытка добавить задачу с пустым заголовком показывает ошибку валидации («Title is required») и помечает поле `aria-invalid`.
- **AC-4**: Страница задач отрисована на сервере: существующие задачи видны без JavaScript.
