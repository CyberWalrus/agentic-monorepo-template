# B4.4. Учёт флаков: repeat-each, дедупликация issues, карантин

**Проблема.** Nightly при каждом падении заводит новый issue без дедупликации; flaky rate (цель в vision меньше 1%) не измеряется.

## Что сделать

- Nightly с `--repeat-each` даёт список нестабильных тестов; на тест заводится один issue с поиском существующего.
- Измерять flaky rate и показывать его в nightly-отчёте рядом с целью из vision.
- Карантин — защищённый файл со списком тестов и сроком: тест из карантина исполняется, но не блокирует. `.skip` остаётся запрещённым.
- Карантин протухает по сроку автоматически: истёкшая запись красит nightly-задачу.

## Критерии приёмки

- Повторное падение одного теста не создаёт второй issue; тест в карантине виден в отчёте с пометкой и сроком; попытка положить тест в карантин без срока красит доску.
