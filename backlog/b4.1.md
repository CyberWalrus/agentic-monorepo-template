# B4.1. Выбор E2E-тестов по фичам

**Проблема.** `e2e` оформлен одним пакетом: любое изменение web или api запускает все E2E, хотя vision обещает «E2E затронутых фич».

## Что сделать

- Отображение путей в фичи: изменение в `apps/web/src/features/<f>/` запускает `e2e/features/<f>/`; изменение в `packages/`, `apps/api`, `src/lib` или конфигах запускает всё.
- Тесты `@critical` идут всегда; в merge queue идёт всё.
- Эвристика может ошибаться только в сторону «запустить больше»; полноту страхует merge queue.

## Критерии приёмки

- Канарейка: изменение в `features/<f>` не запускает чужие фичи, изменение в `packages/` запускает всё; PR с пропущенным тестом ловится merge queue.
