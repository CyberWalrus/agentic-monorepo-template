# B2.3. Пороги покрытия для node-части web и контрактов

**Проблема.** Пороги покрытия настроены только для `apps/api`; node-часть web и контракты не покрыты порогами.

## Что сделать

- Добавить пороги покрытия для node-проекта web (чистые модули из B2.1) и для `packages/contracts`.
- Пороги ставит оператор в режиме обслуживания по правилу ADR 0009 («Пороги»): каждая метрика — фактическое значение, округлённое вниз до целого, минус 2 процентных пункта. Фактические значения и итоговые пороги — в теле PR.

## Критерии приёмки

- Падение покрытия ниже порога красит verify; в PR приведены фактические значения, по которым поставлены пороги.

## Журнал

- 2026-11-15: вопрос о значениях порогов заменён правилом ADR 0009; в `touches` названы защищённые конфиги (`**/vitest.config.ts`), поэтому доска сама показывает «режим обслуживания»; `needs_human` снят. Задачу ведёт оператор.
