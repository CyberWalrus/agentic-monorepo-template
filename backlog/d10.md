# D10. Обновление реального проекта из шаблона

**Проблема.** Механику обновления проверяет синтетический потомок из D9, но цену обновления — сколько конфликтов приходится разбирать руками — покажет только реальный проект. Инструкции для человека пока нет.

## Что сделать

- Инструкция для человека (`copier update`, PR с label `gate-change-approved`) — в документации.
- Правило мажорной версии обновления шаблона.
- Затем автоматизация через Renovate.

## Критерии приёмки

- Инструкция воспроизведена на первом реальном проекте; число ручных конфликтов записано в ADR 0008.
