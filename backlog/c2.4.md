# C2.4. Канарейка табличного теста «чужой ресурс — отказ»

**Проблема.** Табличные тесты «чужой ресурс — отказ» (C2.3) — вторая половина покрытия З6 для политик доступа. Без канарейки их можно обезвредить сужением генерации таблицы, и покрытие З6 молча закончится на тесте перебора (C2.0): канарейка из C2.1 держит живым только перебор.

## Что сделать

- Канарейка в `tools/gate-canaries.ts`: обезвреживание табличного теста C2.3 сужением генерации таблицы красит свой шаг verify.
- Шаг, якорь и способ сужения определить по фактической реализации C2.3.

## Критерии приёмки

- Канарейка направления: суженная генерация таблицы красит гейт; `pnpm canaries` зелёный.

## Журнал

- 2026-11-15: выделена из C2.1 оператором. Объём C2.1 ревью аудита дополнило канарейкой табличного теста C2.3, но тест ещё не существует (цепочка C2.0 → C2.2 → C2.3) — канарейка до теста невозможна. C2.1 отдала канарейку перебора (направление уже опоздало на один PR по компромиссу из C2.0), эта задача догоняет табличную после C2.3. Задача режима обслуживания (`tools/**` под deny): ведёт оператор.
