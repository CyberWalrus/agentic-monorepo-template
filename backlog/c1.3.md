# C1.3. Миграции: гейт «схема совпадает с миграциями» и expand/contract

**Проблема.** С постоянным хранилищем появляется второй источник правды о форме данных — схема базы; без гейта она разъезжается с миграциями и контрактом.

## Что сделать

- Каталог миграций с правилом expand/contract: сначала совместимое расширение, сжатие — отдельным шагом после выката кода.
- Гейт: схема, полученная применением всех миграций с нуля, совпадает со схемой, выведенной из кода/конфигурации Drizzle.
- Каталог миграций в классе `review` (CODEOWNERS): человек видит каждую миграцию.

## Критерии приёмки

- Канарейка: правка схемы без миграции красит гейт; миграция без правки схемы — предупреждение.
