# C9.3. Журнал отказов: счётчик попыток обхода гейтов

**Проблема.** Попытки агентов обойти гейты (отклонённые хуками, заблокированные записи в защищённые пути) нигде не считаются — тренд «перехваченные попытки ослабить гейт» из vision не собирается.

## Что сделать

- Хуки и гейты пишут отказы в журнал вне репозитория (артефакт nightly или файл на раннере): дата, гейт, причина отказа.
- Счётчик попыток по гейтам попадает в отчёт трендов рядом с flaky rate и временем CI.
- Журнал не содержит содержимого кода — только факт отказа и его тип, чтобы не тащить наружу лишнее.

## Критерии приёмки

- Отклонённый хуком обход оставляет запись в журнале; отчёт трендов показывает счётчик по гейтам за период.
