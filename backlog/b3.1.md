# B3.1. CI — источник визуальных базлайнов с одобрением

**Проблема.** Базлайны обновляет человек только локально через Docker; на машине без Docker агент не видит визуальный дифф до CI.

## Что сделать

- При визуальном диффе CI-job выкладывает артефакт с новыми снимками и отчётом.
- Мейнтейнер одобряет их командой в PR или ручным запуском workflow, после чего доверенный workflow коммитит снимки из артефакта в ветку PR.
- В сводку PR идёт список изменённых снимков и ссылка на отчёт.

## Подводные камни

- Workflow, коммитящий базлайны, проверяет автора команды и исполняется из доверенной базы (A1).
- Коммит с `GITHUB_TOKEN` не запускает CI: нужен токен приложения или повторный запуск.
- Рендеринг под эмуляцией amd64 отличается от нативного: источник истины — один, CI.

## Критерии приёмки

- Канарейка: одобренный артефакт доезжает до ветки PR коммитом доверенного workflow; неодобренный — нет.
