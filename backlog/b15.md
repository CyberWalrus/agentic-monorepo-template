# B15. Мутационный контур packages/ui

**Проблема.** packages/ui (6 презентационных компонентов, ~158 строк non-test) полностью вне мутаций: нет конфига, скрипта mutation и stryker-зависимостей (перепроверено find/grep по пакету — пусто); turbo-таск mutation глобальный, канарейка required-tasks сама называет @repo/ui «призраком» (tools/gate-canaries.ts:881-902). Страховка — браузерные unit и визуальные тесты, но мутационно слепая зона не зафиксирована нигде (в отличие от web .tsx, где отложенность задокументирована в architecture.md:116).

## Что сделать

- packages/ui/stryker.conf.json по образцу contracts (node-проект vitest, mutate src/**/*.{ts,tsx} без тестов) с пониженным thresholds.break — во view-слое много выживших JSX-мутантов, это ожидаемо; при необходимости excludes на JSX-мутаторов.
- Скрипт mutation в packages/ui/package.json; зависимости @stryker-mutator/* — версии в catalog: pnpm-workspace.yaml.
- Ночной mutation-full: артефакт mutation-full-ui по образцу mutation-full-web/contracts (nightly.yml:104-110) и проводка в mutation-ratchet (tools/check-mutation-ratchet.ts DOMAINS); канарейка required-tasks — четыре носителя. Телеметрию c9.4 (api-only, telemetry-report.main.ts) не трогаем.

## Критерии приёмки

- pnpm --filter @repo/ui mutation локально зелёный с отчётом reports/mutation/mutation.json; порог откалиброван по пробному прогону.
- Ночной прогон публикует артефакт ui, mutation-ratchet его читает.
- Канарейка required-tasks видит четырёх носителей mutation; pnpm verify зелёный.

## Решение

Выбрано заведение контура (прогон дешёвый, DoD выигрывает) вместо документации слепой зоны. Web .tsx глоб не трогаем: мутация вью-слоя осознанно отложена (B2.2, architecture.md:116, roadmap B11/B2.2 — «не внедрять с обоснованием»); условие возврата: пересмотреть после B11/B2.2. Альтернатива «только задокументировать» отклонена: отличие ui от web — отсутствует документированное отложенное решение.

Задача ведёт оператор (задача будет в режиме обслуживания): touches — stryker-конфиг (deny **/stryker.conf.json), nightly.yml (deny .github/**), tools/check-mutation-ratchet.ts (deny).
