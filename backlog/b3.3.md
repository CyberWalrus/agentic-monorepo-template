# B3.3. Образ с зависимостями для локального визуального прогона

**Проблема.** `pnpm visual` копирует репозиторий в контейнер и ставит зависимости при каждом запуске; на Apple Silicon добавляется эмуляция amd64.

## Что сделать

- Собрать образ с предустановленными зависимостями, слой привязать к `pnpm-lock.yaml`.
- `pnpm visual` переиспользует образ, установка идёт только при смене локфайла.

## Подводные камни

- Бинарные базлайны и образ разделяют одну истину рендеринга: локальный прогон остаётся средством предпросмотра, источником базлайнов остаётся CI (B3.1).

## Критерии приёмки

- Повторный `pnpm visual` без смены локфайла не ставит зависимости; время локального прогона падает замеряемо.
