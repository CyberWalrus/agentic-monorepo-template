# C9.4. Телеметрия обвязки: время CI, flaky rate, доля агентных PR

**Проблема.** Vision перечисляет метрики системы (время CI, flaky rate, доля агентных PR без ручных правок, пропущенные дефекты), но ни одна не собирается — механика гейтов опережает измерения.

## Что сделать

- Сбор метрик из уже существующих источников: длительность jobs из CI, flaky rate из B4.4, счётчик отказов из C9.3, метки «PR агента» из описаний PR.
- Единый отчёт трендов (nightly): метрики за период рядом с целями из vision, дельта к прошлому периоду.
- Бюджет verify (B1) и перф-тренды (A6) читают отчёт, а не считают метрики сами.

## Критерии приёмки

- Отчёт трендов содержит все метрики vision, по которым данные уже собираются; для остальных явно помечено «не собирается, чем закрыть».
