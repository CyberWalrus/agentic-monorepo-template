# D8.4. Снимок ruleset для тегов `v*` и инструкция

**Проблема.** Тег — доверенная база для проектов (З2): по нему Copier находит версию шаблона. Сейчас теги не защищены — незащищённый тег можно переставить (ADR 0008, «Версии»).

Задача ведёт оператор: `touches` — `.github/rulesets/**`.

## Что сделать

- Снимок ruleset `.github/rulesets/tags-v.json` рядом с `main.json`: таргет — теги `v*`; запрет изменения и удаления существующих тегов. Структура снимка — по образцу `main.json`.
- Инструкция создания ruleset тегов в `docs/github-setup.md` (без состояния шаблона — по правилам d8.1): Settings → Rules → Rulesets, по снимку; правка инструкций в том же стиле, что существующий пункт про ruleset `main`.
- Снимок едет в проект (решение d8): в копии оба снимка — для `main` и для тегов `v*`; по ним человек проекта создаёт те же ruleset у себя.

## Критерии приёмки

- `.github/rulesets/tags-v.json` валиден и покрывает теги `v*` запретом изменения/удаления; `pnpm verify` зелёный.
- В `docs/github-setup.md` есть инструкция создания ruleset тегов без id и отметок состояния.
- Демонстрация защиты невозможна до d8.5 (ruleset создаёт человек) — этим критерием задача не блокируется.
