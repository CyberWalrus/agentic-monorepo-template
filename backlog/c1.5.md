# C1.5. Изоляция E2E по рабочему пространству и распараллеливание

**Проблема.** E2E изолируются общим сбросом данных, поэтому visual и perf вынуждены идти последовательно (`SHARED_DATA_LOCK`).

## Что сделать

- Изоляция по арендатору или рабочему пространству на тест: каждый сценарий работает со своими данными и не задевает чужие.
- Снять `SHARED_DATA_LOCK`: visual и perf перестают быть последовательными.
- Миграции к этому моменту уже гейтятся (C1.3), чтобы изоляция не строилась на просядущей схеме.

## Критерии приёмки

- E2E, visual и perf идут параллельно на одном прогоне без взаимного влияния; общий сброс данных остаётся только в `/__test__/reset` для точечных сценариев.
