# C3.2. Production-сервер: entry, Dockerfile, readiness

**Проблема.** Web запускается через `vite preview` — это не production-сервер; production-способа запуска нет ни у человека, ни у агентов.

## Что сделать

- Выбрать серверный entry (Node или Nitro — решение человека), добавить его в оба приложения.
- Dockerfile и readiness-проверка: контейнер стартует, readiness отвечает, сборка минимальна по размеру.
- E2E и перф позже переключаются на тот же способ запуска (отдельная задача C3.4), чтобы тестировалось то, что деплоится.

## Критерии приёмки

- Локальный запуск production-entry зелёный; Docker-образ собирается, readiness отвечает; `vite preview` больше не упоминается как способ запуска web.
