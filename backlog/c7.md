# C7. Генератор фичи

**Проблема.** Каждая новая фича собирается из одних и тех же слоёв руками: контракт, модуль API, фича web, каталог E2E, план. Разброс решений и расход контекста агента — цена каждого запуска.

## Что сделать

- Команда `pnpm gen feature <name>` создаёт заготовки во всех слоях: контракт, модуль API, фича web, каталог E2E, план в `e2e/specs/<name>.md`.
- Канарейка: сгенерированная фича во временном worktree проходит `verify`.

## Критерии приёмки

- Сгенерированная фича во временном worktree проходит `pnpm verify` без правок.
