# E31. Ночной контур: браузер Playwright не установлен на раннере

**Проблема.** Ночь 45013082390 (2026-11-22), три джобы красные с одной вероятной причиной:

- «test count ratchet»: `@repo/ui#test` падает — `browserType.launch: Executable doesn't exist at /home/runner/.cache/ms-playwright/chromium_headless_shell-1255/...` — браузерной сборки 1255 нет ни в кэше, ни установленной на раннере.
- «e2e flake hunt»: playwright-шаг (continue-on-error) не запустил тесты по той же причине, после чего `tools/check-flaky-rate.ts:140` упал на пустом/битом flake.json — каскад.
- PR CI в тот же день зелёный (visual 48 с, e2e 31 с в проверках PR #154) — значит, расхождение в установке/кэше браузера именно у ночных джоб: либо шаг установки отсутствует, либо cache-ключ не учитывает версию браузера Playwright (меняется с обновлением пакета, а не lockfile).

## Что сделать

1. Диагноз: сравнить setup ночных джоб с setup ci.yml (общий ли action, какие шаги установки браузера, ключи кэша); найти, когда началось (между ночами 44722046495 — зелёный flake hunt — и 44894601530 — красный).
2. Фикс установки браузера (шаг `playwright install` с правильным cache-ключом или без кэша) так, чтобы и PR CI, и ночь ставили одну и ту же сборку.
3. Устойчивость `tools/check-flaky-rate.ts` к отсутствию/битому flake.json — отсутствие данных не должно крашить чекер с неинформативной ошибкой (З11); сообщение обязано называть причину.
4. Диспетч ночной — «test count ratchet» и «e2e flake hunt» зелёные (flaky-тесты, найденные честным прогоном, — отдельные issues по контуру b4.4, это не краснота джобы).

## Решение

Править общий setup так, чтобы одна причина работала в обоих контурах; дублирование шага установки только в nightly отклонено как источник следующего расползания. Условие возврата: если окажется, что ci.yml использует другой путь установки — синхронизировать оба на один action.

## Критерии приёмки

- Диспетч ночной: «test count ratchet» и «e2e flake hunt» зелёные.
- check-flaky-rate на пустом входе пишет внятную причину, а не стек.
- PR CI (обычный прогон) остаётся зелёным.
