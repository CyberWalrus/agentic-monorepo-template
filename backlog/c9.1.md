# C9.1. Эталонные задачи: раннер агентных прогонов

**Проблема.** Метрики системы из vision (доля агентных PR без ручных правок, время, итерации) не собираются: нет эталонных задач, на которых их мерить. Аудит трендов 2026-11-14 назвал evals первоочередным гэпом.

## Что сделать

- Набор типовых фич («добавь удаление задачи», «добавь срок») как эталонные сценарии в `tools/` или `docs/`.
- Раннер: агент без участия человека выполняет эталон в чистом worktree; измеряется — дошёл ли до зелёного `verify --full`, число итераций, время, расход токенов.
- Запускать при изменении `.claude/`, `AGENTS.md`, `tools/` и раз в неделю; в каждом PR не нужно (дорого).
- Результаты пишутся в артефакт прогона, тренд — в отчёт nightly.

## Критерии приёмки

- Прогон одного эталона воспроизводим: два запуска подряд дают сопоставимые числа; отчёт содержит все четыре метрики.
