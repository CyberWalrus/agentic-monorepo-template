# C4. Наблюдаемость

**Проблема.** Логи неструктурированы, трейсинга нет, ошибки домена не отличимы по таксономии. Агент при падении E2E не видит логов API — то, что можно проверить детерминированно, не проверяется ничем (З11).

## Что сделать

- Структурные логи с идентификатором запроса, трейсы OpenTelemetry, единая таксономия ошибок на основе типизированных ошибок oRPC.
- Для агента: логи API прикладываются к отчёту Playwright при падении теста (З11).

## Критерии приёмки

- Каждое событие лога несёт идентификатор запроса; ошибки домена типизированы и различимы.
- При падении E2E артефакт отчёта содержит логи API за время сценария.
