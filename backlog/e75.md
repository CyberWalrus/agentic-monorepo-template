# E75. ADR 0012: кэширование статики — по разрешённому файлу, а не по префиксу URL

**Проблема.** `docs/adr/0012-production-server.md:14` (строка «Статика» таблицы «Решения: модель запуска») обещает `Cache-Control: immutable` для `/assets/*` — «хешированные имена клиентской сборки». Это описание прежнего поведения: на `main` признак кэширования — префикс URL (`apps/web/src/server-app.ts:194`, `cacheable: decoded.startsWith('/assets/')`), из-за него `/assets%2F..%2Findex.html` отдавал нехешированный `index.html` с годовым `immutable` (воспроизведено в e55, «Журнал», 2026-11-24). Задача e55 (PR #226) заменила признак на «файл лежит внутри каталога ассетов сборки»: в `resolveStaticFile` — `cacheable: resolved.startsWith(path.resolve(staticRoot, ASSETS_DIR) + path.sep)`, `ASSETS_DIR = 'assets'` (`apps/web/src/server-app.ts:220` и `:171` на ветке `task/e55`), заголовок ставится по `file.cacheable` (`:401-402`). ADR задача не правила: на ветке `task/e55` строка `:14` та же. Найдено ревью безопасности e55 (2026-11-24).

Задача ждёт e55 (`depends_on`): пока PR #226 не смержен, строка ADR точно описывает `main`.

## Что сделать

1. В строке «Статика» (`docs/adr/0012-production-server.md:14`) заменить признак «URL начинается с `/assets/`» на «разрешённый файл лежит внутри каталога ассетов сборки» (`<staticRoot>/assets` — `assetsDir` Vite по умолчанию): `immutable` получает ответ, который реально отдаёт файл из этого каталога; URL с префиксом `/assets/`, разрешающийся вне его (`/assets/../index.html`), `immutable` не получает.
2. Отсылка к e55 (PR #226) с причиной: по префиксу URL traversal из `/assets/` получал годовой `immutable` для нехешированного файла.
3. Записать условие возврата из «Решения 4» e55: если `assetsDir` переопределяют в vite-конфиге — каталог ассетов передаётся опцией, ADR правится тем же PR.
4. Таблицу переформатирует Oxfmt под ширину самой длинной строки — принять его формат (`pnpm verify --only docs,format`).

## Критерии приёмки

- В `docs/adr/0012-production-server.md` не осталось утверждения «`Cache-Control: immutable` для `/assets/*`» как признака по URL; строка «Статика» называет признак — разрешённый файл внутри каталога ассетов сборки — и ссылается на e55.
- Формулировка совпадает с кодом `main` после e55: `cacheable` в `resolveStaticFile` (`apps/web/src/server-app.ts`).
- `pnpm verify` зелёный.
