# C5. Состояния интерфейса и доступность как гейты

**Проблема.** У маршрутов сейчас нет `errorComponent`, `pendingComponent` и `notFoundComponent`; доступность не проверяется ничем. Оба пункта проверяет только `product-logic-reviewer`. По З1 то, что можно проверить детерминированно, должно проверяться гейтом.

## Что сделать

- Гейт: тест перебирает дерево маршрутов и требует наличия `errorComponent`, `pendingComponent`, `notFoundComponent` либо значений по умолчанию на роутере.
- Доступность: проверка axe в компонентных тестах и E2E, нарушение роняет тест.

## Критерии приёмки

- Канарейка: маршрут без компонента ошибки (или роутер без значений по умолчанию) красит гейт.
- Нарушение axe в компонентном тесте или E2E роняет тест.

## Журнал

- 2026-11-14: слито #24 (squash 141eaae) вне доски: ErrorState/NotFoundState/PendingState + тест перебора дерева маршрутов (`apps/web/src/lib/route-states`), axe-хелпер `packages/ui/src/testing/a11y` (компонентные тесты) и `e2e/features/a11y`, визуальный сценарий route-states, планы `e2e/specs/{route-states,a11y}.md` с `[AC-n]` (после C8). Файл перенесён в `done/` задним числом задачей гигиены доски: работа шла по прямому поручению, правило «merge переносит файл» тогда ещё не было гейтом (см. ADR 0007, «Замыкание задачи»).
