# D8.6. Первый тег `v0.1.0`

**Проблема.** Обновление проектов (`copier update`) требует тега — доверенной базы с версий шаблона (ADR 0008, «Версии»). Первый тег ставит человек: это версия шаблона, от которой считаются все потомки.

Действие остаётся человеку (ADR 0007, третий вид `needs_human`). Файлы репозитория задача не меняет, кроме отметки о выполнении.

## Что сделать

- Убедиться, что ruleset тегов Active (d8.5) — иначе тег можно будет переставить.
- Поставить тег `v0.1.0` на `main` (squash-коммит задачи d8.2 или позже — состояние main с рабочим `copier.yml`).
- Проба человеком: `copier copy` из тега во временный каталог, `pnpm install && pnpm verify` в копии — зелёные.
- Отметку о теге занести в `docs/template-state.md`.

## Критерии приёмки

- Тег `v0.1.0` существует на `main` и защищён от изменения/удаления.
- Копия из тега проходит `pnpm verify`; замер и наблюдения — в «Журнал» этой задачи.
- Отметка в `docs/template-state.md`.
