# E25. agent-review: гард первым шагом и пин маркетплейса

**Проблема.** Первый вызов claude-code-action (:61-70) передаёт только settings disableAllHooks — ключа permissions нет: поведение определяется дефолтами action (security.md: auto mode — «непокрытые вызовы решает safety-review»; встроенный blocklist исполнения restrict_untrusted_prs не действует для PR-авторов с write). Шапка (:5-9) обещает whitelist для «ревью в целом» — реализован только во втором шаге (:78-123). Ревьюер читает недоверенный контент PR с ANTHROPIC_API_KEY в env (:63-64), а заявленная угроза «/proc — цепочка утечки ключа» (:9) в шаге 1 не закрыта deny; проектный .claude/settings.json (:34-41) этот пробел тоже не закрывает. Отдельно: plugin_marketplaces (:65) — единственный unpinned внешний источник во всех workflow (прочие uses по SHA; ci.yml:55, action.yml:15-16,25) — компромат маркетплейса = подмена промптов ревьюера, и команды маркетплейса исполняются с меньшими ограничениями, чем собственные ревьюеры репо.

## Что сделать

- Передать в шаг 1 тот же permissions-JSON, что в шаге 2 (defaultMode default; allow Read/Grep/Glob/git diff|log|show; deny Write/Edit/исполнители/Read(/proc/**)), либо объединить вызовы.
- Пиновать plugin_marketplaces на конкретный SHA (синтаксис URL#<sha>, если поддерживается запиненной версией v1.0.284 — проверить до выбора варианта) либо vendor-копия плагина в репозитории с проверкой версии в гейте.
- Согласовать шапку файла с фактической конфигурацией обоих шагов.

## Критерии приёмки

- В конфиге шага 1 есть permissions с defaultMode и явным deny на Write/Edit и Read(/proc/**); шапка соответствует конфигурации обоих шагов.
- Marketplace запинен на SHA (или vendored-копия с проверкой в гейте); поддержка синтаксиса проверена на запиненной версии action.
- Прогон agent-review на тестовом PR зелёный.

## Решение

Выбран одинаковый permissions в оба шага — предсказуемо и не связывает два разных режима ревью (плагин и локальные субагенты); объединение вызовов отклонено. Условие возврата: если CLI не поддерживает пин marketplace по SHA — vendor-копия; если safety-review начнёт блокировать нужные ревью-вызовы — расширять allow, не возвращать auto mode.

Задача ведёт оператор (задача будет в режиме обслуживания): touches — .github/** (deny).
