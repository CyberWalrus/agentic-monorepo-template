**Проблема.** `e2e/fixtures.ts:7`: `import { apiOrigin, resolvePorts } from '../tools/ports.ts'` — e2e импортирует `tools/` (ports, instance, e2e-select, visual-guard). Это законно: e2e — потребитель tools, как и verify. Но правилом не закреплено: в `.dependency-cruiser.cjs` есть запрет «продукт → tools» (`product-not-to-tools`), а разрешение «e2e → tools» явным списком не объявлено. Новый импорт из e2e в любой файл `tools/`, включая код гейтов, пройдёт без сигнала. Аудит владельца, 2026-11-23, «Низкие → Тесты и документация».

## Что сделать

1. Инвентарь фактических импортов e2e → tools (`git grep -n "tools/" -- e2e`) — точный список модулей в «Журнале».
2. Правило в `.dependency-cruiser.cjs`: `e2e → tools` разрешено только модулями из списка; остальное — ошибка с именем правила.
3. Канарейка в `tools/gate-canaries.ts` (шаг `boundaries`): импорт из e2e в модуль вне списка (например, `tools/check-docs.ts`) красит шаг; инвариант «у каждого правила канарейка» держит e47.
4. Замыкание: `.dependency-cruiser.cjs` — deny; `tools/protected-paths.json`, `tools/check-tool-class.ts`, `.claude/settings.json` — правятся тем же PR, если появляется новый файл гейт-контура (шаги `tool-class`, `sandbox` зелёные). Эти три пути в `touches` не объявлены (2026-11-24, волна seed-D7): понадобятся — мини-PR расширения touches до правки.

## Критерии приёмки

- Список модулей в «Журнале»; на текущем дереве шаг `boundaries` зелёный.
- Импорт e2e → модуль вне списка красит шаг `boundaries` (саботаж — в «Журнале»); канарейка из п.3 зелёная.
- pnpm verify зелёный; шаги `tool-class` и `sandbox` зелёные.

## Решение

Разрешение списком, а не исключением каталога: `e2e` целиком вне правила — та же дыра классом ниже. Условие возврата: если список модулей меняется чаще двух раз за месяц — закрепить разрешение на уровне подкаталога `tools/` для тестовой инфраструктуры и записать в «Журнале».

Задача ведёт оператор (задача будет в режиме обслуживания): touches — `.dependency-cruiser.cjs`, `tools/gate-canaries.ts` (deny); условное замыкание в touches не объявлено (2026-11-24, волна seed-D7; понадобится — мини-PR расширения touches).
