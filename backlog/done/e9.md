# E9. Перенос `tools/` к классам защиты по замыканию гейтов (ADR 0014)

Задача ведёт оператор: `touches` попадают в защищённые пути (режим обслуживания, ADR 0009). Решение и полные обоснования — [ADR 0014](../../docs/adr/0014-tools-protection-classes.md).

## Что сделать

Один PR («один гейт на один PR» — гейт здесь один контур: классификация и его держатель):

1. `tools/protected-paths.json`: blanket `tools/**` из `deny` убрать; `deny` = явный список замыкания из ADR 0014 (42 файла) + `tools/hooks/**` + `tools/test/**`; в `review` добавить `tools/**` и `package.json`.
2. Разделение doctor: `tools/backlog-doctor.ts` (deny, его вызывает nightly вместо `pnpm backlog doctor`), CLI `tools/backlog.ts` остаётся без логики doctor и уходит в review (убрать из deny-списка, он замещается `backlog-doctor.ts`).
3. Гейт `tools/check-tool-class.ts`: пересчитывает замыкание структурным выводом входных точек (методология ADR 0014) и красит, если (а) файл замыкания не в `deny` защищённого списка; (б) `deny`-запись внутри `tools/` вне замыкания; (в) шаг verify ссылается на несуществующий скрипт или ссылка не резолвится. Список читать только из `protected-paths.json`.
4. Канарейка: фикстурный тест в `tools/test/` (синтетическое дерево с файлом замыкания вне deny — чекер обязан упасть; зелёный случай проходит) + wiring-канарейка шага по образцу B4.1. Сначала канарейка красная, потом гейт.
5. Шаг verify (fast), job `static`, `needs` у `gate`, бюджет в verify-budgets.json.
6. `.claude/settings.json`: `denyWrite` = новый `deny` (гейт `sandbox` держит равенство).
7. Документы тем же PR: architecture.md §3.5 «целевое» → «действует», AGENTS.md, «Изменения гейтов» в PR.

## Критерии приёмки

- Канарейка падает до внедрения чекера и зелёная после (показать в PR).
- `pnpm verify --full` и `pnpm canaries` зелёные в режиме обслуживания.
- Замер `pnpm verify` до и после (правило §4.4): замедление — дефект.
- Deny-список в `protected-paths.json` побайтово равен `denyWrite` (гейт sandbox зелёный).
- check-tool-class красится на вынутый из deny файл замыкания (демо в PR) и на лишнюю deny-запись.
