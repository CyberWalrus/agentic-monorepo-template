# B4.2. Turborepo affected на уровне задач

**Проблема.** Turborepo affected работает на уровне пакетов; изменения общего пакета будят все его потребители, даже когда задача не зависит от изменённых файлов.

## Что сделать

- Попробовать `futureFlags.affectedUsingTaskInputs`: affected на уровне задач, а не пакетов.
- Сравнить время CI и число запущенных задач на типовых PR до и после; флаг экспериментальный — при деградации откатить и записать причину.

## Критерии приёмки

- Замер на типовых PR приложен к PR; флаг включён или отказ задокументирован с цифрами.

## Журнал

- 2026-11-21 01:30 MSK: окно обслуживания не потребовалось — флаг включался только для замера и откат (итоговый дифф — журнал задачи). Замер: dry-run (turbo run typecheck test build e2e --affected --dry=json) на синтетической незакоммиченной правке общего файла packages/contracts/src/tasks.ts, одинаковое дерево для всех трёх прогонов: **без флага 25 задач, с флагом 25 задач, контроль 25** — множества совпадают полностью. Причина: граф задач плотный — build/e2e каждого пакета зависят от ^build/transit всех зависимостей, изменение контрактов по построению будит всех потребителей независимо от гранулярности входов. **Отказ задокументирован с цифрами (AC)**: флаг не включён, turbo.json не изменён. Условие пересмотра: после разряжения графа (снятие ^build-зависимостей у e2e или правки globalDependencies) — повторить замер. Флаг принят turbo 2.11.10 без ошибки (dry-run прошёл в обоих режимах).
