# C3. Окружение, production-сервер, деплой

**Проблема.** Схемы окружения нет: `process.env` читается где угодно, `.env.example` ни с чем не сверяется. Web запускается через `vite preview` (`apps/web/package.json`) — это не production-сервер. Preview-окружений нет ни человеку для одобрения визуальных изменений, ни агентам для исследовательского тестирования. Задача декомпозируется.

## Что сделать

- Схема окружения на Zod в каждом приложении. Читает окружение один модуль. Гейт: правило Oxlint, запрещающее `process.env` вне этого модуля, и проверка `.env.example` по схеме.
- Выбрать серверный entry на Node или Nitro, добавить Dockerfile и readiness-проверку.
- Preview-окружение на PR: человеку для одобрения визуальных изменений, агентам для исследовательского тестирования.
- E2E и перф должны идти против того же способа запуска, что и production.

## Критерии приёмки декомпозиции

- Файлы задач с `depends_on` и `touches`; канарейка направления: `process.env` вне модуля окружения красит линт.
