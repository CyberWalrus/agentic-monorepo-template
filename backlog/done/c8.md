# C8. Трассировка критериев приёмки

**Проблема.** Критерии приёмки в `e2e/specs/<feature>.md` не связаны с тестами: у критерия может не быть ни одного теста, и это видно только ревьюеру. Таблица «критерий, тест» в PR заполняется руками.

## Что сделать

- Критерии получают идентификаторы (`AC-1`). Тесты ссылаются на них в названии или аннотации.
- Гейт: у каждого критерия есть хотя бы один тест, каждый идентификатор в тестах существует в плане.
- Таблица «критерий, тест» в PR генерируется, а не заполняется руками.

## Критерии приёмки

- Канарейка: критерий без теста (или идентификатор теста без критерия) красит гейт.
- Таблица «критерий, тест» в PR генерируется гейтом.

- 2026-11-14: слито #25 (2df7b41) вне доски: гейт трассировки — двусторонняя сверка планов `e2e/specs` ↔ тестов по `[AC-n]` в заголовках (З1), генерация таблицы «критерий — тест» в PR. Файл перенесён в `done/` задним числом задачей гигиены доски (ADR 0007, «Замыкание задачи»).
