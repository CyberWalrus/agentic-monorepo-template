# E38. Пинить инвариант e24 тестом: после checkout PR head — ни pnpm/npm/npx/node, хуки выключены

**Проблема.** Инвариант доверенного workflow «после шага Checkout PR head не исполняется ничего из PR-дерева» (e24) держится только на комментариях шапки — этот класс пробела пропустил исходный дефект b3.1 (строка в docs/escaped-defects.md от PR e24). Проводочные тесты tools/test/visual-approval.test.ts (describe «проводка», :99) пинят валидатор/артефакт/диспетч/fork-гвардию, канарейка gate-canaries.ts — байт-в-байт блок валидатора; правка в режиме обслуживания может молча вернуть pnpm install после checkout — ни один гейт не заметит.

## Что сделать

1. В describe «проводка» tools/test/visual-approval.test.ts добавить ассерты по тексту workflow: (а) после шага «Checkout PR head without executing it» нет строк, запускающих pnpm/npm/npx/node (не в комментариях); (б) env шагов «Commit baselines to the PR branch» и «Push baselines to the PR branch» содержит LEFTHOOK='0'; (в) env шага коммита не содержит GH_TOKEN.
2. Режим обслуживания (tools/test/** — deny): maintenance.json с путём touches по протоколу ADR 0009.
3. pnpm verify зелёный; канарейку в gate-canaries.ts не дублировать — тест живёт в test:hooks и красит срыв уже сейчас.

## Критерии приёмки

- Тест красный на саботаже: в копии workflow после шага checkout добавлена строка `pnpm install` (или убран LEFTHOOK='0' у шага commit/push) — ассерт падает с названием нарушенного инварианта (саботаж — в «Журнале»).
- На текущем workflow тест зелёный; pnpm verify зелёный.

## Решение

Одна точка охраны (тест проводки) достаточна: файл читает сам workflow, дрейф комментариев от поведения тест ловит структурно. Альтернатива — канарейка-саботаж — избыточна при живом тесте. Условие возврата: если ассерты по тексту оказываются хрупкими к переформатированию YAML — заменить разбором на парсере YAML (тот же тест, та же защита).

Задача ведёт оператор (задача будет в режиме обслуживания): touches — `tools/test/**` (deny); окно обслуживания по протоколу ADR 0009 с записью времён в «Журнал».
