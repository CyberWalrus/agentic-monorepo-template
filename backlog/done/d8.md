# D8. Copier: копия без файлов разработки и её канарейка

**Проблема.** Задача не помещается в один PR: проба, `copier.yml`, исключения, канарейка, тег. Зависит от D6: пока документы, которые едут в проект, ссылаются на `docs/roadmap.md`, копия не пройдёт `docs:check`.

## Что сделать

Проба Copier на этом репозитории во временном каталоге (до любых правок): создать копию, выполнить в ней `pnpm install` и `pnpm verify`, записать, что сломалось; проверить, что файлы демо-домена не приезжают повторно при обновлении. Затем `copier.yml` с вопросами (имя проекта, владелец) и `_exclude`; `copier.yml` в `deny` и CODEOWNERS; проверка, что в нём нет `_tasks` и `_migrations`; один файл с закреплённой версией Copier; ruleset для тегов `v*` в `.github/rulesets/` и в `docs/github-setup.md`; канарейка копии; исключение в З5; первый тег `v0.1.0`.

## Решение (2026-11-15)

Выбор делегирован человеком агенту в сессии 2026-11-15; принимается merge PR с этой правкой (ADR 0009, «Развилки в задачах»).

- **Демо-домен копируется при создании проекта и не приезжает повторно при обновлении** — вариант по умолчанию из ADR 0008. Конфиги гейтов рассчитаны на существующие `apps/` и `packages/`: пустой проект без них не пройдёт `pnpm verify`, а рабочий пример нужнее пустого каркаса. Условие возврата: исключать демо-домен вместе с генератором фичи (задача C7).
- **`docs/github-setup.md` едет в проект** как инструкция (класс «шаблон»): проекту нужны тот же ruleset, labelы и политика `pull_request_target`, иначе `gate-integrity` не станет обязательным check. Состояние самого репозитория шаблона — отметки ✅, id ruleset и политики, имя владельца — выносится в отдельный файл, который перечислен в `_exclude`.
- **Снимки ruleset в `.github/rulesets/` едут в проект** (класс «шаблон»): по ним человек создаёт ruleset в интерфейсе GitHub. В копию попадают оба снимка — для `main` и для тегов `v*`.
- **Владелец в `CODEOWNERS`** подставляется из ответа Copier (ADR 0008); канарейка проверяет, что имени владельца шаблона в копии нет.
- Задачи, которые выйдут из декомпозиции и трогают `copier.yml`, `.github/**` или `tools/**`, ведёт оператор (ADR 0009). Первый тег `v0.1.0` ставит человек: защищённый тег — версия шаблона для проектов.

## Критерии приёмки

- Канарейка зелёная: копия проходит `pnpm verify`, `git ls-files` в ней не содержит `docs/roadmap.md`, `docs/research/`, задач шаблона и имени владельца шаблона.
