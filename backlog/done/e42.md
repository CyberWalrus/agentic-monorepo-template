# E42. Канарейки гейтов: холодный старт browser-тестера выглядит как «НЕ УПАЛ»

**Проблема.** Раннер канареек `tools/run-gate-canaries.ts` повторяет прогон verify в рабочем зеркале только по сигналу: `verifyInWorktreeWithSignalRetry` (`:120-142`) смотрит лишь на регулярку `SIGNAL_KILL` и делает один повтор. Иной сбой среды — холодный старт browser-тестера (vitest browser mode в свежем клоне: первый запуск Chromium) — вердиктом не признаётся: шаг, связанный с browser-тестами, не доходит до проверки саботажа, а раннер печатает «НЕ УПАЛ» — ложную тревогу «гейт пропустил саботаж». Проявилось в PR #165 и #135. По инвентаризации, в канарейке копии шаблона (`tools/run-template-copy-canary.ts`) повтор уже есть — сверить при захвате. Цена: агент и ревьюер разбирают несуществующую дыру, а ложные «НЕ УПАЛ» приучают не верить канарейкам.

## Что сделать

1. По логам запусков канареек PR #165 и #135 (job `canaries`) зафиксировать сигнатуру холодного старта: какая канарейка, какой шаг, что в выводе шага (таймаут старта, отсутствие отчёта, пустой прогон) — дословно в «Журнал».
2. В раннере: вердикт «НЕ УПАЛ» — только когда шаг действительно отработал и не увидел саботажа. Сбой среды по сигнатуре из п.1 — отдельный класс (как SIGTERM/SIGKILL): один повтор, повторный сбой — громкая ошибка «среда, не вердикт» с exit 1, отличимая от «НЕ УПАЛ».
3. Прогрев: запустить browser-тестер до первой канарейки на нём (один раз за прогон), если сигнатура из п.1 это подтверждает.
4. Тест `tools/test/run-gate-canaries.test.ts` на классификацию вывода шага: саботаж пойман / среда (повтор) / среда повторно (громкая ошибка) / НЕ УПАЛ.
5. Замыкание: `tools/run-gate-canaries.ts`, `tools/test/**` — deny; `tools/protected-paths.json`, `tools/check-tool-class.ts`, `.claude/settings.json` — правятся тем же PR, если появляется новый файл гейт-контура (шаги `tool-class`, `sandbox` зелёные). Эти три пути в `touches` не объявлены (2026-11-24, волна seed-D7): понадобятся — мини-PR расширения touches до правки.
6. Строка в `docs/escaped-defects.md` тем же PR: в графе «что добавлено» — тест классификации из п.4.

## Критерии приёмки

- Сигнатура холодного старта записана в «Журнале» со ссылкой на лог (run, job, шаг).
- Тест классификации зелёный; на выводе из п.1 раннер не печатает «НЕ УПАЛ».
- В CI job `canaries` — 10 последовательных прогонов без ложного «НЕ УПАЛ» (список run — в «Журнале»); настоящий саботаж по-прежнему красит канарейку (ночная джоба `gate canaries` зелёная, локальный саботаж по инструкции раннера красит).
- Строка добавлена в `docs/escaped-defects.md`; pnpm verify зелёный; шаги `tool-class` и `sandbox` зелёные.

## Решение

Классификация «среда ≠ вердикт» вместо общего повтора всех падений: повтор всего подряд превращает канарейки в генератор зелёного. Условие возврата: если сигнатуру холодного старта не удаётся отличить от настоящего «НЕ УПАЛ» — оставить fail-громкое поведение (среда = красная с названием причины) и записать в «Журнале», что отличие не доказано.

Задача ведёт оператор (задача будет в режиме обслуживания): touches — `tools/run-gate-canaries.ts`, `tools/test/**`, `.github/**` (deny); условное замыкание в touches не объявлено (2026-11-24, волна seed-D7; понадобится — мини-PR расширения touches).
