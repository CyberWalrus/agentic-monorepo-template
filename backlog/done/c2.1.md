# C2.1. Канарейка гейта политик доступа

**Проблема.** Тест перебора политик доступа (C2.0) — блокирующая проверка. По З6 у каждого гейта есть канарейка, которая доказывает, что проверка краснеет на нарушении: без неё тест можно обезвредить (сузить перебор, пропустить процедуру), и он останется зелёным.

## Что сделать

- Канарейка в `tools/gate-canaries.ts`: процедура без политики доступа, добавленная в копию контракта, красит шаг `test` пакета контрактов.
- Канарейка табличного теста «чужой ресурс — отказ» (C2.3): он обезвреживается так же, как тест перебора — сужением генерации таблицы.
- Перебор в тесте C2.0 должен идти по самому объекту контракта, а не по списку имён: если это не так, канарейка это покажет — завести задачу на исправление теста, а не подгонять канарейку.

## Критерии приёмки

- Канарейка направления: процедура без политики доступа красит гейт; `pnpm canaries` зелёный.
