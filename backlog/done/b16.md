**Проблема.** Конвенция де-факто существует и последовательна (все каталоги kebab), но нигде не зафиксирована как стандарт: только точечные правила трёх артефактов (tools/gen.ts:9 — вход генератора; docs/evals.md:16 — name-фронматтер сценариев; перепроверка grep по docs/, AGENTS.md, README.md — общего правила нет). С заглавными — 48 путей (git ls-files | grep -cE '[A-Z]' = 48): 26 — PascalCase-файлы кода (5 в apps/web/src/features/tasks/: CreateTaskForm.tsx/.test.tsx, TasksPage.tsx/.test.tsx/.module.css; 21 в packages/ui/src/{button,error-state,not-found-state,pending-state,task-item,text-field}/), 22 — имена, фиксированные внешними инструментами дословно.

## Что сделать

- Зафиксировать стандарт в AGENTS.md и architecture.md 2.7: пути, каталоги и имена файлов — строчные, слова через дефис; единый список исключений — только имена, требуемые внешними инструментами (SKILL.md, AGENTS.md, CLAUDE.md, README.md, LICENSE, Dockerfile, CODEOWNERS, CODEOWNERS.jinja, routeTree.gen.ts).
- Переименовать 26 файлов (git mv) без изменения публичных экспортов (Button остаётся Button): CreateTaskForm.tsx → create-task-form.tsx, TasksPage.tsx → tasks-page.tsx, Button.tsx → button.tsx, ErrorState.tsx → error-state.tsx и т.д.; обновить импорты (apps/web/src/routes/index.tsx:3 импортирует TasksPage, внутренние импорты фич и ui).
- Скриншот-каталоги packages/ui переедут за именами тест-файлов (packages/ui/vitest.config.ts resolveScreenshotPath зеркалит имя теста): git mv каталогов **screenshots** (Button.visual.test.tsx/, TaskItem.visual.test.tsx/, TextField.visual.test.tsx/) и переустановка базлайнов через CI с одобрением человека (ADR 0015).

## Критерии приёмки

- git ls-files | grep -E '[A-Z]' возвращает ровно список исключений из стандарта (48 → 19: 26 файлов кода и 3 скриншот-каталога переименованы).
- Стандарт и единый список исключений записаны в AGENTS.md и architecture.md 2.7.
- pnpm verify зелёный (boundaries, registries, docs); pnpm visual зелёный после одобрения базлайнов; pnpm e2e зелёный.
- Публичные экспорты и API пакетов не изменились (дифф содержимого — только строки импортов).

## Решение

Выбрано переименование по стандарту «строчные+дефис» с минимальным списком внешне-фиксированных исключений. Альтернатива «задокументировать PascalCase как вторую конвенцию» (рекомендация линзы) отклонена: мандат — единый стандарт; трения только две — базлайны скриншотов и импорты, оба закрываются git mv и стандартным процессом одобрения визуальных изменений. Условие возврата: если обновление базлайнов блокирует PR дольше цикла — разделить на два PR: сначала apps/web (без базлайнов), затем packages/ui.

Задача ведёт оператор (задача будет в режиме обслуживания): переименования затрагивают **/**screenshots**/** (deny, tools/protected-paths.json:4) и правят AGENTS.md; базлайны обновляет CI с одобрением человека.
