# E13. Канон документации: дрейф формулировок и DX-полировка

**Проблема.** Аудит 2026-11-20 (линза DX) нашёл кластер дрейфа — единственный P0 аудита: канон для агентов учит механике, которую ADR объявил провалившейся; статусы принятых решений не доведены; документы противоречат друг другу о фактах. Агент воспроизводит задокументированный сбой.

## Что сделать — дрейф

- AGENTS.md: «Закрывающий PR переносит файл в `backlog/done/`» — а ADR 0007 (колонка «Почему») называет это правило старым («дважды не сработало: C5, C8») и заменяет переносом сразу после захвата с красным docs-гейтом. Привести к формулировке ADR 0007 и скила `task-board`.
- Шесть ADR висят со статусом «предложено (принимается merge …)» при смерженных и внедрённых решениях: 0008, 0009, 0010, 0013, 0015, 0016 — проставить «принято (внедрено …)» по образцу ADR 0002.
- README: «на 2026-11-17 тега ещё нет» — тег v0.1.0 поставлен 2026-11-19 (`docs/template-state.md`), `docs/github-setup.md` уже учит копированию из него.
- Список «Написаны:» в `docs/architecture.md` обрывается на ADR 0013 — дописать 0014–0016.
- Правила оператора продублированы в шести местах (README, AGENTS.md, architecture.md, roadmap.md, vision.md, ADR 0009) и уже разошлись: канон — в ADR 0009 + краткая таблица в AGENTS.md, остальные — ссылки.
- Стек-строки AGENTS.md и README разошлись (sherif, Lefthook, «Vite (Rolldown)») — синхронизировать или ссылать один на другой.
- Карта структуры в AGENTS.md не описывает `e2e/specs/` и `e2e/agents/` — дополнить.
- Правило для `packages/ui` — см. «Решение».

## Что сделать — DX

- Строка про установку pnpm (corepack) в «Быстрый старт» README — первый шаг новичка с чистым node падает.
- Указатель на требования окружения (Docker, Chromium, телеметрия turbo) из AGENTS.md — сейчас они только в README, а AGENTS.md — канон агентов.
- `verify --only` в таблицы команд AGENTS.md и README — поднабор реализован (`tools/verify.ts`), но не упомянут.
- Минимальный `.editorconfig` (utf-8, lf, 2 пробела для yaml/json/md).
- Убрать текстовые ссылки на `docs/roadmap.md` из файлов, едущих в копию (AGENTS.md, README), — roadmap в `_exclude` copier (ADR 0008 требовал убирать такие ссылки до первого тега), а `docs:check` проверяет только markdown-ссылки, текст в бектиках проходит.

## Решение (правило ui)

- **В AGENTS.md разрешить «domain-shaped presentation» в `packages/ui` при условиях: нет импортов контрактов/транспорта, шейп данных объявлен локально в пакете.** Почему: `TaskItem` уже соответствует этому неявному контракту; переезд в фичу трогает защищённые визуальные базлайны ради чистоты декларации — цена выше пользы.
- Альтернатива (ui — только generic-примитивы, task-item уезжает в фичу) — условие возврата: в `packages/ui` поедут компоненты второй фичи, или появится второй потребитель шаблона с другим доменом — тогда переосмыслить границу.

## Критерии приёмки

- `pnpm verify --only docs` зелёный; по каждому пункту списка — grep подтверждает, что старая формулировка исчезла из всех вхождений; карта структуры включает `e2e/specs/` и `e2e/agents/`.
