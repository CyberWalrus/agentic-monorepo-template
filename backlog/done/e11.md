# E11. Переразметка `touches` открытых задач под классы ADR 0014

После e9 все задачи с blanket `touches: tools/**` показываются доской свободными (review), даже когда реально правят гейты, — известное fail-open окно ADR 0014. Эта задача закрывает окно: переписывает `touches` открытых задач точными путями. Правки чужих задач идут отдельным PR — этот PR и есть такой отдельный.

## Что сделать

- Для каждой открытой задачи с blanket `tools/**` записать в `touches` точные пути планируемых правок (по замыслу задачи; классификация и держатели — таблица в [ADR 0014](../../docs/adr/0014-tools-protection-classes.md)).
- Задачи, создающие новые гейты, пометить в тексте «ведёт оператор» (ADR 0009) — независимо от показаний доски.

## Критерии приёмки

- После переразметки `pnpm backlog list` показывает режимными 24 задачи, свободными — b3.3, c4, c7, c9.1, e4, e8 (+ c9.2 после снятия блокировки по c9.1) — критерий приёмки из ADR 0014. Отклонение от классификации ADR — расхождение разбирается в «Журнале» этого PR, а не молча правится под число.
- Ни одна закрытая задача не менялась; грамматика `touches` (литеральные пути и `каталог/**`) соблюдена.
