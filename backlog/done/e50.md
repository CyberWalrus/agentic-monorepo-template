# E50. guard-bash: три формы запрещённых команд мимо правил

**Проблема.** Правила `tools/hooks/guard-bash.ts` матчат буквальные формы команд:

- `:36` — обновление базлайнов ловится только как `(vitest|playwright) … (-u|--update)`; `-u` после разделителя `--` (`pnpm test -- -u`, `pnpm vitest run -- --update-snapshots`) не матчится. По аудиту эти формы стоят в allow-листе хука; где именно — `tools/analyze-command.ts` или адаптер, — установить при захвате (в `guard-bash.ts` allow-списка нет).
- `:46` — force-push ловится как `git push …`; `git -C <dir> push -f` проходит: между `git` и `push` стоит глобальная опция.
- `:50` — деструктивные команды ловятся как `checkout --`; `git checkout <ref> -- <файл>` проходит, а команда отбрасывает изменения файлов — для агента разрушительная, как `git checkout --`.

Аудит владельца, 2026-11-23, «Средние → Гейты и защита» и «Низкие → Безопасность и стабильность». Дыры прошли все гейты — строк в `docs/escaped-defects.md` нет.

## Что сделать

1. Регрессии в `tools/test/guard-bash.test.ts` (красные до фикса): `pnpm test -- -u`; `pnpm vitest run -- --update-snapshots`; `git -C ../other push -f`; `git -C dir push --force`; `git checkout HEAD -- tools/protected-paths.json`; `git checkout main -- file`. Контрольные (должны остаться разрешёнными): `pnpm test -- --reporter=verbose`; `git -C dir status`; `git checkout other-branch`.
2. Правила: глобальные опции git (`-C <dir>`, `-c key=value`) пропускать перед подкомандой; для `checkout <…> -- <…>` матчить `--` в хвосте команды с любыми аргументами до него; для базлайнов матчить `-u|--update…` в любом месте хвоста после `--`.
3. Разобраться с allow-листом из п.1 «Проблемы»: если команда вида `pnpm test …` проходит по нему целиком, правило базлайнов применять до allow-листа — запрет сильнее разрешения.
4. Замыкание: `tools/protected-paths.json`, `tools/check-tool-class.ts`, `.claude/settings.json` — правятся тем же PR, если появляется новый файл гейт-контура (шаги `tool-class`, `sandbox` зелёные). Эти три пути в `touches` не объявлены (2026-11-24, волна seed-D7): понадобятся — мини-PR расширения touches до правки.
5. Строка в `docs/escaped-defects.md` тем же PR: в графе «что добавлено» — регрессии из п.1.

## Критерии приёмки

## Решение

Нормализация команды перед правилами (снять глобальные опции git, найти разделитель `--`), а не добавление ещё одной буквальной формы в каждую регулярку: перечисление форм проигрывает всегда. Условие возврата: если нормализация даёт ложные отказы на легитимных командах агентов (по журналу отказов `tools/denial-journal.ts`) — откатить нормализацию до точечных форм и записать в «Журнале».

Задача ведёт оператор (задача будет в режиме обслуживания): touches — `tools/hooks/**`, `tools/analyze-command.ts`, `tools/test/**` (deny); условное замыкание в touches не объявлено (2026-11-24, волна seed-D7; понадобится — мини-PR расширения touches). Пересекается с e45 и e51 по `tools/analyze-command.ts`: кто мержит вторым — ребейз.
