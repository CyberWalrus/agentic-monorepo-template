# C10.3. Адаптер ZCode: плагин с hooks.json на CLI из `tools/`

**Проблема.** ZCode не исполняет хуки уровня проекта (проверено 2026-11-14): контура L0 в основном клиенте нет, агенты ZCode не защищены хуками в момент действия.

## Что сделать

- Плагин ZCode с `hooks/hooks.json`, который вызывает те же CLI из `tools/`, что и хуки Claude Code.
- Формат входа хуков ZCode совместим с Claude Code (snake_case-поля, код выхода 2 блокирует) — по документации; прогоном не проверено, в задании прогон.
- Канарейка: плагин подключён в CI-окружении агента, попытка ослабить гейт блокируется и видна в журнале отказов (C9.3).

## Критерии приёмки

- В ZCode блокирующий хук останавливает запись в защищённый путь тем же CLI, что и в Claude Code; расхождение форматов входа задокументировано.

## Журнал

- 2026-11-20 21:43–21:52 MSK: окно обслуживания (правки классов защиты не потребовались — замыкание гейтов не выросло; файл снят до коммита; далее правки только review-класса). Реализация: плагин `tools/zcode-plugin/` (`.claude-plugin/plugin.json` + `hooks/hooks.json` + `hooks/run-cli.sh` + README). Дизайн: (1) плагин — тонкая проводка, CLI те же, что исполняют хуки Claude Code (C10.1): session-start/protect-paths/guard-bash/protect-result/lint-changed-file/stop-verify, тот же набор и matcher'ы — согласованность держит тест; (2) `run-cli.sh` fail-closed по З4: плагин в отрыве от репозитория (кэш-копия) не находит `tools/hooks/` и блокирует exit 2 с объяснением — контур не может тихо исчезнуть; (3) открытие по ходу: CLI защищённых гейтов сигналит deny по протоколу Claude Code (JSON `permissionDecision:deny`, exit 0), а ZCode по документации блокирует на exit 2 — обёртка транслирует JSON-deny в exit 2 с причиной в stderr, блокировка работает по обоим механизмам; (4) smoke-тест тем же прогоном: блок защищённого пути (exit 2 + причина), пропуск обычного файла (exit 0), fail-closed кэш-копии, сверка набора CLI/matcher'ов с `.claude/settings.json`. Урок окружения: тест задаёт `CLAUDE_PROJECT_DIR` явно — переменная сессии-хоста указывает на другой чекаут и `relative()` даёт `..`.
- Честное ограничение: формат входа хуков ZCode — «по документации» (как и записано в задаче); живая активация плагина в клиенте — за человеком при включении (README, раздел «Установка»). Связка с журналом отказов — интеграционная точка C9.3 (в очереди оператора); пока отказы видны в stderr и ответе инструмента.
