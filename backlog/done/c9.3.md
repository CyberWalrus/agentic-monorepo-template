# C9.3. Журнал отказов: счётчик попыток обхода гейтов

**Проблема.** Попытки агентов обойти гейты (отклонённые хуками, заблокированные записи в защищённые пути) нигде не считаются — тренд «перехваченные попытки ослабить гейт» из vision не собирается.

## Что сделать

- Хуки и гейты пишут отказы в журнал вне репозитория (артефакт nightly или файл на раннере): дата, гейт, причина отказа.
- Счётчик попыток по гейтам попадает в отчёт трендов рядом с flaky rate и временем CI.
- Журнал не содержит содержимого кода — только факт отказа и его тип, чтобы не тащить наружу лишнее.

## Критерии приёмки

- Отклонённый хуком обход оставляет запись в журнале; отчёт трендов показывает счётчик по гейтам за период.

## Журнал

- 2026-11-20 22:25–22:55 MSK: окно обслуживания (protected-paths.json + KNOWN_GATES + denyWrite под tools/denial-trend.ts; denial-journal.ts — фасад, реализация в hooks/lib), снято до коммита. Реализация: (1) журнал — JSONL вне репозитория (~/.agentic-monorepo-template/denials.jsonl, DENIAL_JOURNAL_PATH перекрывает — CI пишет в reports/ и отдаёт артефактом); (2) хуки пишут факт: protect-paths → protected-path-write, guard-bash → категории (baseline-update/hooks-skip/force-push/destructive-git/protected-path-write/oversized-command), protect-result → protected-file-restored, fail-closed → fail-closed; в записи только date/gate/reason — ни команд, ни кода (тест приватности); (3) gate-integrity.yml: при красном — запись в reports/denials.jsonl + артефакт gate-denials (попытка ослабить гейты в CI учтена); (4) тренд: `pnpm denial:report [--days 30]` — счётчик по гейтам за период (записи старше периода не считают, битые строки не роняют). Живая проверка: реальный вызов protect-paths на защищённый путь оставил запись в журнале.
- Урок: журнал — реализация внутри tools/hooks/lib.ts (хуки самодостаточны: синтетические деревья тестов копируют только tools/hooks/, внешний импорт ронял 35 тестов); tools/denial-journal.ts — тонкий фасад для тренда.
