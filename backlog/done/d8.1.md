# D8.1. Разделить `docs/github-setup.md`: инструкция и состояние шаблона

**Проблема.** `docs/github-setup.md` едет в проект как инструкция (решение d8, класс «шаблон»), но перемешивает инструкции с состоянием шаблона — отметки ✅, id ruleset `27137353` и политики `13436`, даты. Состояние в копии проекта бессмысленно и вводит в заблуждение: там ничего из этого не настроено.

## Что сделать

- Инструкции (как настроить ruleset `main`, labelы, политику `pull_request_target`, секреты) остаются в `docs/github-setup.md` — без состояния: без отметок выполнения, id, дат и имён владельца шаблона.
- Состояние («что уже настроено в этом репозитории»: id ruleset и политики, отметки ✅, даты) — в новый dev-only файл `docs/template-state.md`, который попадёт в `_exclude` (задача d8.2).
- Правило ссылок: на `docs/template-state.md` может ссылаться только документ, который сам не едет в проект (сейчас — `docs/roadmap.md`). Ссылка из едущего документа сломала бы `docs:check` в копии: гейт проверяет все markdown-файлы, а файла состояния в копии не будет.
- Команды для человека (`gh label create`, создание ruleset и т.п.) остаются в инструкции и не должны опираться на идентификаторы, существующие только в шаблоне (конкретные id — только в состоянии).
- Пункты, которые появятся в следующих задачах d8 (ruleset тегов `v*` — d8.4, создание проекта Copier — d8.2), зарезервировать заголовками без содержимого либо добавить в своей задаче: место в структуре файла определяется здесь, чтобы d8.2/d8.4 не переуступали структуру.

## Критерии приёмки

- `pnpm verify` зелёный, `docs:check` в том числе.
- В `docs/github-setup.md` нет отметок ✅, id ruleset/политики, дат состояния и имён владельца шаблона.
- `docs/template-state.md` существует, содержит прежнее состояние; ссылка на него — из `docs/roadmap.md`, ссылок на него из едущих документов нет.
- В `docs/github-setup.md` нет ссылок на `docs/roadmap.md`, `docs/research/`, `backlog/` (гейт docs ловит битые ссылки уже в шаблоне).
