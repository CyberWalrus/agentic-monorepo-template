# E22. Документ «как удалить часть шаблона»

**Проблема.** Шаблон предлагает одну форму (ADR 0008), потребитель с другой потребностью (только API, только web, без базы, без визуальных тестов) вырезает части руками — и не знает, что при этом сломается. Исследование e6 (docs/research/2026-11-template-profiles.md, таблица «что убрали × что сломалось», прогоны 2026-11-21) дало фактуру, но живёт в docs/research, который не едет в копию (`_exclude` copier.yml), а README/AGENTS об удалении частей не говорят ничего.

## Что сделать

- `docs/removal.md` (едет в копию): по каждой части — web, api, Postgres, визуальные тесты — чек-лист «что удалить → что за этим краснеет → что переделать в CI», из таблицы и раздела «Инструкция» исследования e6.
- Явное предупреждение в разделе про api: до e20 удаление `apps/api` выключает mutation-гейт молча; документ обновить после слива e20 (убрать предупреждение, добавить новый шаг в чек-лист).
- Ссылка на документ из README.md (раздел про структуру) — так, чтобы docs-гейт остался зелёным (команды в README сверяются с workspace, `tools/check-docs.ts:114`).
- Пункт «если нужна другая форма проекта — удаляйте по документу, профили Copier не вводятся (ADR 0008, e6)».

## Критерии приёмки

- `docs/removal.md` существует, четыре раздела-части, каждый с чек-листом и списком краснеющих гейтов из исследования e6; ссылки в документе не битые (docs-гейт зелёный).
- README ссылается на документ; других правок README нет.
- Документ не противоречит ADR 0008: одна форма, профили не вводятся.
- В копии шаблона (`pnpm canaries` — канарейка копии) документ присутствует: он не в `_exclude` copier.yml.
