# C11. Обновление стека

**Проблема.** Каталог `catalog:` отстаёт от реестра npm, обновления идут по одному пакету и без учёта групповых зависимостей (образ CI, `pnpm visual`, конфиги). Таблица сверки с реестром npm на 2026-11-12 — в `docs/roadmap.md`, раздел «Стек»: TypeScript 7.1 (бета), Playwright 1.65, Vitest 5.1, pnpm 12.18, Turborepo 2.11.11, Oxlint 1.93 / Oxfmt 0.78, oRPC 2 (бета), Hono 5 (rc), StrykerJS актуален, Drizzle 1.0 не вышел.

## Что сделать

- Обновлять по таблице «Стек» в `docs/roadmap.md`, сверку повторять при каждом заходе.
- Playwright обновлять одной группой: образ в CI, Test Agents, `pnpm visual`.
- Oxfmt всё ещё 0.x и может менять форматирование: обновлять отдельным PR.
- Беты и rc (TypeScript 7.1, oRPC 2, Hono 5, Drizzle 1.0) не трогать до стабильных релизов; для каждого записано условие возврата в таблице.
- После стабильного TypeScript 7.1 проверить, перешли ли на него dependency-cruiser и StrykerJS, и только тогда убирать `packageExtensions`.

## Критерии приёмки

- `pnpm verify --full` зелёный после каждой группы обновлений; беты в каталог не попадают.
