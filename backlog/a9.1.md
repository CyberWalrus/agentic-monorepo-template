# A9.1. Включить строгую базу в ruleset `main` и авто-удаление веток в GitHub

**Проблема.** Снимок ruleset — файл в репозитории; защита включается только в интерфейсе GitHub, у агентов туда доступа нет (ADR 0002: настройки GitHub делает мейнтейнер). Пока настройка не применена, A9 остаётся бумажной.

Действие остаётся человеку (ADR 0009, «Что остаётся человеку»). Файлы репозитория задача не меняет, кроме отметки о выполнении.

## Что сделать

- Settings → Rules → Rulesets → ruleset `main` → Require status checks → включить «Require branches to be up to date before merging».
- Settings → General → Pull Requests → включить «Automatically delete head branches».
- Удалить в origin ветки уже закрытых задач: их перечисляет `pnpm backlog list` и `pnpm backlog doctor`.
- Отметку о выполнении (дата) занести в `docs/template-state.md` — отдельным PR человека или оператором по поручению.

## Критерии приёмки

- PR с веткой, отставшей от `main`, GitHub не даёт слить до обновления.
- После merge ветка PR удаляется сама; в origin нет веток закрытых задач.
- Отметка в `docs/template-state.md`.
