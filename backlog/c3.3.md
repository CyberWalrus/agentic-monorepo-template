# C3.3. Preview-окружение на PR

**Проблема.** Preview-окружений нет ни человеку для одобрения визуальных изменений, ни агентам для исследовательского тестирования.

## Что сделать

- Preview-окружение на PR на базе production-entry из C3.2: ссылка в PR, жизнь до merge или закрытия.
- Для визуального одобрения (B3.1) preview даёт человеку живой дифф без локального Docker; агентам — исследовательское тестирование вне гейтов.
- Доступ к preview с данными тестового контура, не production-секретами.

## Критерии приёмки

- PR получает ссылку на живое окружение автоматически; после merge окружение гасится; секреты production в preview не попадают.
