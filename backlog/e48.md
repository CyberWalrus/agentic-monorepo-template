# E48. openapi-compat: без базы сравнения гейт сравнивает HEAD с HEAD

**Проблема.** `packages/contracts/scripts/openapi-compat.ts:633`: если `git merge-base HEAD origin/main` не резолвится, скрипт берёт базой `HEAD` (комментарий `:638-640`: «Копия шаблона (канарейка d8.3) — git без origin… База = HEAD»). Для канарейки копии это осознанно, но условие выведено из окружения, а не из явного флага: любой прогон без `origin/main` — чистый клон с одной веткой, worktree без remote-ссылки, shallow clone — получает базу, равную текущему состоянию: находок ноль, гейт breaking changes зелёный. В шапке скрипта обещан fail-closed: нет базы — красный. Аудит владельца, 2026-11-23, «Средние → Гейты и защита». Дыра прошла все гейты — строки в `docs/escaped-defects.md` нет.

## Что сделать

1. Регрессия в `packages/contracts/scripts/openapi-compat.test.ts`: репозиторий без `origin/main` и без явной базы — гейт обязан упасть с сообщением «база не определена» (инструкция: `git fetch origin main` или передать `--base <ref>`; в CI база приходит в `TURBO_SCM_BASE`), а не сравнивать HEAD с HEAD.
2. Откат к HEAD — только по явному флагу (например `--allow-head-base`), который ставит одна канарейка копии шаблона (`tools/run-template-copy-canary.ts`); по умолчанию — `fail([...])`.
3. Записать в «Журнале», где вызывается гейт (шаг verify, job CI) и откуда там берётся база, — чтобы уверенность «в CI база есть» опиралась на файлы, а не на предположение.
4. Замыкание объявлено в touches: `tools/protected-paths.json`, `tools/check-tool-class.ts`, `.claude/settings.json` — правятся тем же PR, если появляется новый файл гейт-контура или меняется класс скрипта (сегодня класс review через `packages/contracts/**`; сверить с b8).
5. Строка в `docs/escaped-defects.md` тем же PR: в графе «что добавлено» — регрессия из п.1.

## Критерии приёмки

- Регрессия из п.1 красная до правки и зелёная после; с флагом из п.2 гейт в копии шаблона работает как прежде (`pnpm probe:plugin` и канарейка копии зелёные).
- Таблица вызовов гейта с источником базы — в «Журнале».
- pnpm verify зелёный; шаги `tool-class` и `sandbox` зелёные; строка добавлена в `docs/escaped-defects.md`.

## Решение

Явный флаг вместо вывода из окружения: «сравнить не с чем» — состояние, которое называет тот, кто его создал намеренно, а не любой клон без remote. Альтернатива — оставить откат и описать его в шапке — отклонена: описание не мешает локальному прогону печатать зелёное на breaking change. Условие возврата: если явный флаг ломает путь канарейки копии, который нельзя править в этом PR, — временно вернуть откат с громким warning в выводе и записать в «Журнале» срок возврата.

Задача ведёт оператор (задача будет в режиме обслуживания): touches объявляют замыкание гейта (`tools/protected-paths.json`, `tools/check-tool-class.ts`, `.claude/settings.json` — deny) и `tools/run-template-copy-canary.ts`; сам скрипт сегодня класса review. Пересекается с e46 по `openapi-compat.ts`: кто мержит вторым — ребейз.
