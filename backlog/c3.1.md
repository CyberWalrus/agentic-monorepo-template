# C3.1. Схема окружения на Zod и запрет `process.env` вне модуля

**Проблема.** Схемы окружения нет: `process.env` читается где угодно, `.env.example` ни с чем не сверяется.

## Что сделать

- Схема окружения на Zod в каждом приложении; окружение читает один модуль, дальше по приложению идут типизированные значения.
- Гейт: правило Oxlint, запрещающее `process.env` вне модуля окружения.
- Проверка `.env.example` по схеме: пример валиден и полон.

## Критерии приёмки

- Канарейка направления: `process.env` вне модуля окружения красит линт; невалидный `.env.example` красит verify.
