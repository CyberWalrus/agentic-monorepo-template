# C10.1. Логика хуков — CLI в `tools/` без привязки к агенту

**Проблема.** Логика хуков живёт внутри формата Claude Code; основной клиент ZCode исполняет только пользовательские хуки и хуки плагинов, хуки уровня проекта игнорирует — контура L0 в ZCode нет (ADR 0007).

## Что сделать

- Перенести логику каждого хука в CLI в `tools/`: проверка гейта, формат входа — JSON на stdin, код выхода 2 блокирует.
- Хуки в `.claude/` становятся тонкими адаптерами, вызывающими CLI.
- Каждый CLI тестируется напрямую, без запуска агента.

## Критерии приёмки

- Все решения хуков принимаются в `tools/`; адаптеры в `.claude/` не содержат логики, кроме вызова CLI; CLI покрыты тестами.
