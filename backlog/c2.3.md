# C2.3. Табличные тесты «чужой ресурс — отказ»

**Проблема.** Точечные тесты доступа пишутся наугад; нужна таблица, покрывающая каждую процедуру с владельцем.

## Что сделать

- Для каждой процедуры с политикой «владелец» есть случай «чужой ресурс, отказ» и «свой ресурс, успех» — генерируются перебором контракта, а не пишутся руками.
- Таблица «процедура × случай» видна в отчёте тестов: пустая строка красит набор.

## Критерии приёмки

- Канарейка: удаление проверки владельца из любой доменной процедуры красит табличный тест без его ручной правки.
