# B2.2. StrykerJS для `apps/web` и `packages/contracts`

**Проблема.** Мутационное тестирование настроено только для `apps/api`; логика web и схемы контрактов не мутируются.

## Что сделать

- Подключить StrykerJS к `apps/web` (только node-проект, мутируются `*.ts` без `*.tsx`) и к `packages/contracts`.
- В PR мутировать только изменённые файлы; полный прогон остаётся в nightly.
- Учесть: vitest-runner по умолчанию берёт только тесты, связанные с мутируемым файлом через импорты; для тестов без такой связи настройку выключить.

## Критерии приёмки

- Канарейка: мутант в логике оптимистичного обновления (из B2.1) или в схеме контракта убивается тестами.
- Мутационный прогон в `pnpm verify` укладывается в текущий бюджет времени или бюджет расширен явно.
