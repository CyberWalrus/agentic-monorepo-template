# C10. Переносимость

**Проблема.** Хуки и скилы лежат в `.claude/` и работают только в Claude Code; основной клиент — ZCode — исполняет только пользовательские хуки и хуки плагинов, хуки уровня проекта игнорирует (документация ZCode, проверено 2026-11-14). Другие агенты читают `AGENTS.md`, но контура L0 в ZCode нет (ADR 0007). Задача декомпозируется: упаковка плагина, перенос логики хуков в `tools/`, адаптер — отдельные направления.

## Что сделать

- Упаковать `.claude/` (хуки, скилы, ревьюеры) в плагин Claude Code для переиспользования в других репозиториях.
- Логику хуков держать в `tools/` как CLI без привязки к агенту, адаптер под конкретного агента делать тонким.
- Адаптер для ZCode: плагин с `hooks/hooks.json`, который вызывает те же CLI из `tools/`. Формат входа хуков совместим с Claude Code (snake_case-поля, код выхода 2 блокирует) — по документации, прогоном не проверено.
- Условие выполнено 2026-11-14: основной клиент — ZCode, поэтому адаптер актуален.

## Критерии приёмки декомпозиции

- Файлы задач с `depends_on` и `touches`; для адаптера ZCode предусмотрен свой ADR (новый контур L0).
