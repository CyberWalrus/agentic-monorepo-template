# C10.3. Адаптер ZCode: плагин с hooks.json на CLI из `tools/`

**Проблема.** ZCode не исполняет хуки уровня проекта (проверено 2026-11-14): контура L0 в основном клиенте нет, агенты ZCode не защищены хуками в момент действия.

## Что сделать

- Плагин ZCode с `hooks/hooks.json`, который вызывает те же CLI из `tools/`, что и хуки Claude Code.
- Формат входа хуков ZCode совместим с Claude Code (snake_case-поля, код выхода 2 блокирует) — по документации; прогоном не проверено, в задании прогон.
- Канарейка: плагин подключён в CI-окружении агента, попытка ослабить гейт блокируется и видна в журнале отказов (C9.3).

## Критерии приёмки

- В ZCode блокирующий хук останавливает запись в защищённый путь тем же CLI, что и в Claude Code; расхождение форматов входа задокументировано.
