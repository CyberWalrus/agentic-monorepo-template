# D9. Классы владения и смешанные файлы

**Проблема.** Обновление конфликтует только там, где один файл правят обе стороны; таблица классов пишется по результату пробы D8, не заранее (ADR 0008).

## Что сделать

По результату пробы составить таблицу: каждый файл из `git ls-files` попадает ровно в один класс — шаблон, проект или смешанный (ADR 0008). Для каждого смешанного файла решить, делится ли он на часть шаблона и часть проекта. Для `AGENTS.md`: правила шаблона остаются в нём, сведения о продукте уходят в отдельный файл, на который он ссылается обычным текстом (ZCode не раскрывает `@import`). Отдельно решить судьбу `pnpm-lock.yaml`: при обновлении он конфликтует всегда и должен перегенерироваться (З10).

## Критерии приёмки

- Таблица записана в ADR 0008; синтетический потомок (копия из предыдущего тега, правка в части проекта, обновление до текущего) проходит без конфликтов в файлах классов «шаблон» и «проект».
