# C10.2. Плагин Claude Code из `.claude/` для других репозиториев

**Проблема.** Хуки и скилы лежат в `.claude/` и работают только в Claude Code и только в этом репозитории; шаблон не может переиспользовать собственную обвязку.

## Что сделать

- Упаковать `.claude/` (хуки-адаптеры, скилы, ревьюеры) в плагин Claude Code с манифестом.
- Плагин переиспользуется в других репозиториях без копирования файлов; пути к CLI из C10.1 резолвятся относительно репозитория-потребителя.
- Проба плагина в стороннем тестовом репозитории до merge.

## Критерии приёмки

- В чистом репозитории с подключённым плагином скил вызывается, хук блокирует ослабление гейта; в этом репозитории поведение не изменилось.
