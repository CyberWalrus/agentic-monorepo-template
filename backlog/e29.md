# E29. Дельта-гейт бандла не вооружён в живой конфигурации

**Проблема.** Живой ruleset main содержит только [gate, gate-integrity] в required_status_checks (gh api линзы, дважды, стабильно), метки из чек-листа github-setup.md §2 не созданы: рост бандла сверх бюджета сейчас не блокирует merge — красный локальный bundle-delta можно проигнорировать. Снапшот (.github/rulesets/main.json:27) прямо называет это «сознательным окном до создания label»; джоба bundle-approval уже существует и fail-closed (gate-integrity.yml:155-243). Попутно: живой ruleset дрейфует от снапшота — required_approving_review_count 0, require_code_owner_review false, require_last_push_approval false против снапшота 1/true/true (main.json:16-21); почему канарейка ruleset-drift (tools/test/ruleset-drift.test.ts:58-79) это не красит — не установлено.

## Что сделать

- Оператор исполняет ручные шаги docs/github-setup.md §1–§2 в интерфейсе GitHub: метка из чек-листа §2, добавление bundle-approval в required_status_checks живого ruleset.
- Синхронизировать снапшот .github/rulesets/main.json с живым состоянием после настройки.
- Установить, почему ruleset-drift не красит дрейф живого ruleset от снапшота; починить канарейку или задокументировать её границу.
- Правка живого ruleset — только полным payload: GET → правка нужных полей → PUT всего документа, затем GET-after-PUT со сверкой каждого критичного поля и локальный `node tools/check-ruleset-drift.ts` (exit 0). Урок e30 (журнал backlog/done/e30.md): частичный PUT a9.1 молча сбросил три PR-параметра — строка реестра от 2026-11-22 в docs/escaped-defects.md.

## Критерии приёмки

- gh api rulesets main показывает bundle-approval среди required_status_checks; метка из чек-листа github-setup.md §2 существует.
- Снапшот .github/rulesets/main.json согласован с живым правилом; ruleset-drift зелёный.
- Тестовый PR с ростом бандла сверх порога блокируется до ручного одобрения (лог/скриншот в PR задачи).
- Причина пропуска дрейфа канарейкой ruleset-drift установлена (фикс или осознанная граница).

## Решение

Выбрано исполнение документированных ручных шагов — дизайн ADR 0013 предполагает именно эту проводку, альтернатив нет. Условие возврата: если ruleset-drift не видит отдельные поля правил — расширить снапшот-сверку канарейки отдельной задачей.

Задача ведёт оператор (задача будет в режиме обслуживания): touches — .github/** (deny); ключевое действие — в интерфейсе GitHub.
