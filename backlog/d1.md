# D1. Общие инструкции агентов — в AGENTS.md

**Проблема.** ZCode читает только `AGENTS.md`: `CLAUDE.md` не читается, `@import` не раскрывается (документация ZCode, проверено 2026-11-14). Таблицы скилов и ревьюеров лежат в `CLAUDE.md`, поэтому основной клиент их не видит.

## Что сделать

Перенести из `CLAUDE.md` в `AGENTS.md` три раздела: «Скилы» (с путями к файлам `SKILL.md`: агент без поддержки скилов читает их как документы), «Субагенты-ревьюеры» (как роли и этапы, без привязки к механизму субагентов) и правило для Healer из «Playwright Test Agents». В `CLAUDE.md` остаются четыре темы: хуки, песочница, режим обслуживания, MCP. `AGENTS.md` должен остаться коротким (architecture.md 3.9).

## Критерии приёмки

- Три раздела есть в `AGENTS.md` и отсутствуют в `CLAUDE.md`; `docs:check` зелёный.
