# B19. Мутационный контур packages/ui — возврат по триггерам ADR 0022

**Проблема.** b15 доказал, что честный мутационный контур для packages/ui на StrykerJS 10.1.1 невозможен: активация мутанта идёт через `process.env` рантайма мутированного кода (`@stryker-mutator/instrumenter`, syntax-helpers), а весь код пакета исполняется в Chromium-iframe (vitest browser mode) — оба раннера (vitest-runner и command runner) дают ложных «выживших»: 53/53 мутантов при зелёном начальном прогоне, таймаутные псевдо-убийства зависят от загрузки. Слепая зона задокументирована строкой в ADR 0022 (таблица слепых зон) и в architecture.md §2.5. До триггера контур-муляж не заведён сознательно.

## Что сделать

- При срабатывании технического триггера ADR 0022 (поддержка browser mode в раннере StrykerJS или эквивалентном мутаторе браузерных тестов) либо по отдельному ADR о выносе поведенческой логики ui из `.tsx` в node-тестируемые модули `*.ts` — завести контур по плану b15: `packages/ui/stryker.conf.json`, скрипт `mutation`, зависимости `@stryker-mutator/*` из каталога, ночной артефакт `mutation-full-ui`, проводка храповика (DOMAINS + CLI `--ui`), канарейка required-tasks на четыре носителя.
- Правки потребуют режим обслуживания оператора: touches перечисляют все затронутые deny-пути (список снят с эксперимента b15); расширение окна на CLI и `gate-canaries.ts` зафиксировано в журнале b15 как осознанное (b15 эти файлы не правила).
- До триггера задачу не брать (З6, needs_human).

## Критерии приёмки

Как у b15: локальный зелёный `pnpm --filter @repo/ui mutation` с отчётом `reports/mutation/mutation.json` и порогом от пробного прогона по правилу ADR 0009; ночной артефакт читается mutation-ratchet; канарейка required-tasks видит четырёх носителей; `pnpm verify` зелёный.

## Решение

Отложено до триггера (b15, 2026-11-23). Альтернатива «теневой jsdom-набор тестов ui» без ADR отклонена: меняет уровень тестирования компонентов (скил writing-tests предписывает browser mode) — если человек выберет её, задача переформулируется. Ссылки: журнал b15 (эксперимент, доказательства, условия возврата), ADR 0022 (таблица слепых зон, технический триггер).
