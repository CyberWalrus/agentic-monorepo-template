# Реестр пропущенных дефектов

**Пропущенный дефект** (escaped defect) — дефект, прошедший все гейты и найденный после merge. Метрика обвязки: [docs/vision.md](vision.md), «Метрики системы» — каждый такой случай рассматривается как пробел в проверках. Вопрос, который задаёт реестр каждому случаю: какой контур должен был это поймать и появился ли он. Без реестра нельзя ответить, становится ли обвязка лучше.

## Как ведётся

- Строку добавляет тот же PR, который чинит дефект (правило — [AGENTS.md](../AGENTS.md), раздел «Всегда»).
- В строке либо новый гейт или канарейка, либо запись «гейт невозможен, потому что …».
- Перед записью случай сверяется с историей git и файлами `backlog/done/`: номер PR или задачи из памяти аудита мог быть назван неточно.
- В копии из шаблона проект ведёт свои строки по тем же правилам (класс владения файла — [ADR 0008](adr/0008-template-distribution.md), «Классы владения по файлам»).
