# ADR 0004: Песочница Bash-агента на уровне ОС

- Статус: принято (внедрено 2026-11-13, roadmap A2 пункт 4 — последняя закрытая часть A2)
- Дата: 2026-11-13
- Контекст: [architecture.md](../architecture.md) (З4, З10), [roadmap.md](../roadmap.md) (задача A2, «Порядок работ»), [ADR 0003](0003-result-based-protection.md)

## Проблема

Хуки агента (ADR 0003) — подсказка и проверка по результату внутри процесса агента. Сознательный обход они не останавливают (заявленное исключение — перезапись state тем же uid). Границей для сознательного обхода оставалась только L3 (CI из доверенной базы), а запрет записи в защищённые пути не был встроен в сам инструмент (З4): хук может не успеть, агент может работать в хосте без хуков проекта (ZCode, класс C10). Нужен запрет на уровне ОС: Seatbelt на macOS, bubblewrap на Linux.

## Решение

| Область            | Решение                                                                                                                                                                                                                                                                                              | Почему                                                                                                                                                                                                                        | Альтернатива и когда к ней вернуться                                      |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| Включение          | `sandbox.enabled: true`, `autoAllowBashIfSandboxed: true` (по умолчанию): команды внутри песочницы одобряются автоматически — контур остаётся пригодным для работы агента                                                                                                                            | Песочница, под которой нельзя работать, отключают через день                                                                                                                                                                  | —                                                                         |
| Запись             | `filesystem.denyWrite` — ровно `deny` из `tools/protected-paths.json`; расхождение ловит гейт `sandbox` в `pnpm verify` (З10); `allowWrite: ["~/Library/pnpm"]` — store вне worktree                                                                                                                 | Список-источник один: защищённые пути; «два источника одной границы» — рассинхрон по определению                                                                                                                              | —                                                                         |
| Выход из песочницы | `allowUnsandboxedCommands: false` (strict): механизм повторного запуска с `dangerouslyDisableSandbox` отключён, команды идут только в песочнице                                                                                                                                                      | Иначе запрет на уровне ОС обходится одним повтором команды                                                                                                                                                                    | —                                                                         |
| Сеть               | `allowLocalBinding: true` (dev-серверы e2e), `allowAllUnixSockets: true` (docker CLI → демон для `pnpm visual`), `allowedDomains: [registry.npmjs.org, *.npmjs.org]` (pnpm install). Прочая сеть закрыта; расширение списка — labeled PR в `settings.json`                                           | Эксперименты показали: браузерные тесты и e2e живут на localhost; реестр нужен только установке зависимостей                                                                                                                  | —                                                                         |
| Недоступность      | `failIfUnavailable: true`: на машине без Seatbelt/bubblewrap агент не работает вовсе (нативный Windows песочницу не поддерживает — агент там не запускается по определению)                                                                                                                          | Контур, который молча исчезает именно когда нужен, противоречит З4; у ADR 0003 зафиксировано, что «проверка слепа» обязана шуметь                                                                                             | `false` — если появится машина-хост без bubblewrap и без альтернативы     |
| Режим обслуживания | Конфликт: `disableAllHooks` не выключает песочницу, а `denyWrite` на `tools/**` + strict делают обслуживание гейтов через агента невозможным. Решение — maintenance-профиль: `settings.local.json` (файл только для человека, в `deny`) = `{"disableAllHooks": true, "sandbox": {"enabled": false}}` | Режим обслуживания — по определению действие человека: хранитель замка не выписывает себе ключ. Альтернативы отклонены: постоянное сужение `denyWrite` ослабляет границу ради редкого режима; «ручной обход» команд неследуем | Узкий производный `denyWrite` — если режим обслуживания станет постоянным |

## Доверенная граница

Песочница — граница против **процессов агента**: даже сознательная команда не пишет в защищённые пути и не выходит из песочницы (strict). За её пределами остаются: сам хост вне песочницы (человек), коммиты (остаются под gate-integrity, ADR 0002) и перезапись state контура (ADR 0003 — единственное тихое исключение, теперь и оно ограничено: tmp-каталог процесса). Модель ADR 0003 (L0 — случайный обход, L3 — сознательный) ужесточается: значительная часть сознательных обходов останавливается на L0.

## Откат

`sandbox.enabled: false` или удаление блока — labeled PR (файл в `deny`). Гейт `sandbox` падает вместе с блоком и напомнит либо восстановить, либо убрать проверку тем же PR.
