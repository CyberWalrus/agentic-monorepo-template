# ADR 0004: Песочница Bash-агента на уровне ОС

- Статус: принято (внедрено 2026-11-13, roadmap A2 пункт 4 — последняя закрытая часть A2)
- Дата: 2026-11-13
- Контекст: [architecture.md](../architecture.md) (З4, З10), задача A2, [ADR 0003](0003-result-based-protection.md)

## Проблема

Хуки агента (ADR 0003) — подсказка и проверка по результату внутри процесса агента. Сознательный обход они не останавливают (заявленное исключение — перезапись state тем же uid). Границей для сознательного обхода оставалась только L3 (CI из доверенной базы), а запрет записи в защищённые пути не был встроен в сам инструмент (З4): хук может не успеть, агент может работать в хосте без хуков проекта (ZCode, класс C10). Нужен запрет на уровне ОС: Seatbelt на macOS, bubblewrap на Linux.

## Доверенная граница

Песочница — граница против **процессов агента**: сознательная команда не пишет в защищённые пути файловой операцией и не выходит из песочницы (strict, без исключений команд). Заявленные остатки, где границей остаётся ADR 0003 (снимок, detect-and-revert) + L3:

- **docker.sock**: демон работает вне песочницы и пишет в хост (`docker run -v` доносит до защищённых путей). Сокет сужен до docker.sock ровно потому, что `pnpm visual` требует Docker; ssh-agent и прочие сокеты закрыты. Отменить изменение может снимок; закоммиченное останавливает L3.
- **Запись самого каталога-записи** (`mv tools tools.bak`): глоб `tools/**` не покрывает запись каталога; переименование меняет старые пути и ловится снимком.

За границей: сам хост вне песочницы (человек), коммиты (gate-integrity, ADR 0002), перезапись state контура (ADR 0003 — тихое исключение). Модель ADR 0003 (L0 — случайный обход, L3 — сознательный) ужесточается: значительная часть сознательных обходов останавливается на L0.

## Режим обслуживания: известное тихое окно

Пока `settings.local.json` существует: хуки выключены (включая `SessionStart` — напомнить о нём технически нечем) и песочница отключена. Границей остаётся CI (label-flow) и ревью. Человек удаляет файл после работы — чек-лист в [CLAUDE.md](../../CLAUDE.md). Одноразовая альтернатива для одиночной команды: `claude --settings '{"sandbox":{"enabled":false}}'` — файл не создаётся, забыть невозможно.

## Откат

`sandbox.enabled: false` или удаление блока — labeled PR (файл в `deny`). Гейт `sandbox` падает вместе с блоком и напомнит либо восстановить, либо убрать проверку тем же PR.
