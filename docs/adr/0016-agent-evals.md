# ADR 0016: Эталонные агентные прогоны (evals)

- Статус: предложено (принимается merge этого PR человеком)
- Дата: 2026-11-19
- Задача: C9.1 (оператор, режим обслуживания), журнал задачи — протокол AC и итоги ревью плана. Связанные: [ADR 0009](0009-operator-delegation.md), [ADR 0014](0014-tools-protection-classes.md), ADR 0010.

## Контекст

Метрики системы из vision (доля агентных PR без ручных правок, итерации, время) не собираются: нет эталонных задач и раннера. Аудит трендов 2026-11-14 назвал evals первоочередным гэпом. Тяжёлый агентный прогон в каждом PR — не вариант (минуты и доллары токенов на каждый PR), задача C9.1 прямо запрещает. Нужен контур измерения: агент без участия человека выполняет эталонную фичу в чистом worktree, раннер меряет результат.

## Отвергнуто

- **Гейт в verify каждого PR.** Минуты агента и доллары токенов на каждый PR; задача прямо говорит «в каждом PR не нужно».
- **Composite action для установки CLI (обход парсера tool-class).** Установка вне разбора гейта — игра с гейтом, а не осознанное исключение; `pnpm add` честен и попадает в ревью диффа.
- **devDependency `@anthropic-ai/claude-code`.** Тяжёлая зависимость каждому worktree и каждому pnpm install шаблона ради L5-контура.
- **Тренд-отчёт в этом PR.** Единый отчёт трендов — задача c9.4 (сбор из существующих источников); здесь — артефакт со стабильной схемой, c9.4 его читает.

## Последствия

- Метрики vision «доля агентных PR без ручных правок» пока не покрываются этим контуром: он меряет эталонные фичи, не реальные PR; доля без ручных правок — задача c9.4.
- Скип без секрета: до настройки `ANTHROPIC_API_KEY` контур скипается с напоминанием — настройка секрета остаётся человеком (ADR 0009, «Что остаётся человеку»).
- Новая deny-область `tools/evals/*.ts`: правки раннера — режим обслуживания или label `gate-change-approved`.
- Ночной cron (понедельник 05:00 UTC) добавляет еженедельную стоимость LLM-токенов — человек видит её в PR и может остановить отклонением.
